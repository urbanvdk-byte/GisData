# GisData

Интерактивная схема пешеходной доступности, Владивосток. Статический сайт, без локального сервера. GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Модель
- Сафонова, Никифорова, Озеро (предварительная точка по адресу Сафонова, 14).
- 300, 500, 1000 м. Граф пешеходных путей OSM через Overpass. Оба режима используют одинаковый граф.
- Режим 50/10: стоимость ребра = горизонтальная длина + 5 × абсолютная разность высот концов ребра; длинные участки разбиваются на части до 25 м. Высоты AWS Terrain Tiles Terrarium, z14. Dijkstra; учитываются частично достижимые рёбра.
- Полигоны — приближённые коридоры шириной 25 м от достижимых путей, сетка 10 м, а не нормативное покрытие зданий. Метод учёта накопленных подъёмов и спусков выбран для анализа, не является утверждением действующего норматива. Привязка к ближайшему узлу до 100 м, без проверки подхода к нему. Ограничения OSM и ЦМР, включая мосты, тоннели, лестницы, неполные теги доступа и временные препятствия, влияют на точность.
- Данные и подложка загружаются в браузере. При сбое внешних API результат не подменяется кругами. Экспорт GeoJSON и печать.

Источники: OpenStreetMap (ODbL), CARTO, AWS Terrain Tiles / Mapzen. Экспериментальная версия; сквозной расчёт в браузере пока не проверен.
